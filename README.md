# پنل موزاییک (Mosaic Admin)

قالب پنل مدیریتی HTML/CSS/JS — راست‌چین، فارسی، آماده برای فروشگاه‌ها، پنل‌های کاربری و ابزارهای مدیریتی.

## ساختار فایل‌ها

```
mosaic-admin-template/
├── index.html                     داشبورد اصلی (نقطه ورود پنل)
├── landing.html                   صفحه فروش/دموی محصول
├── css/style.css                  تمام استایل‌ها
├── js/script.js                   منطق تعاملی مشترک
├── auth/
│   ├── login.html                 ورود
│   ├── register.html              ثبت‌نام
│   ├── verify-email.html          تایید ایمیل با کد
│   ├── forgot-password.html       فراموشی رمز عبور
│   ├── verify-reset-code.html     تایید کد بازیابی
│   └── reset-password.html        تعیین رمز عبور جدید
├── orders/
│   ├── orders.html                جدول سفارش‌ها
│   └── new-order.html             ثبت سفارش جدید
├── products/
│   └── add-product.html           افزودن/ویرایش محصول
├── reports/
│   ├── sales-analytics.html       تحلیل فروش
│   └── transactions.html          تراکنش‌ها
├── checkout/
│   ├── cart.html                  سبد خرید
│   ├── checkout.html              تسویه حساب + انتخاب درگاه پرداخت
│   ├── payment-success.html       نتیجه پرداخت موفق
│   ├── payment-failed.html        نتیجه پرداخت ناموفق
│   └── payment-pending.html       نتیجه پرداخت در انتظار تایید
├── settings/
│   └── settings.html              تنظیمات حساب و پنل
└── errors/
    ├── 404.html                   صفحه پیدا نشد
    ├── 403.html                   دسترسی غیرمجاز
    └── 500.html                   خطای سرور
```

هر صفحه با مسیر نسبی صحیح به `css/style.css` و `js/script.js` لینک شده (بسته به عمق پوشه، `../css/style.css` یا مستقیم). اگر فایلی را جابه‌جا می‌کنید، مسیرهای import را متناسب اصلاح کنید.

## هویت رنگی (DELTIZE + کلاسیک)

پیش‌فرض قالب برند **دلتیز** است: سرمه‌ای هویتی (`#1E3A8A`) روی سایدبار، فیروزه‌ای (`#06B6D4`) به‌عنوان رنگ تاکیدی، و زمینه‌ی سفید/خاکستری روشن برای محتوا. دکمه‌ی «◆» بالای هر صفحه بین این تم و تم قدیمی «کلاسیک» (سرمه‌ای تیره + طلایی) سوییچ می‌کند. برای تغییر رنگ‌های دلتیز، متغیرهای `--accent`, `--accent-dim`, `--brand-navy` را در `css/style.css` ویرایش کنید.

## ریسپانسیو / موبایل‌فرست

طراحی بر پایه‌ی breakpointهای ۴۸۰ / ۷۶۸ / ۹۸۰ پیکسل بازبینی شده: سایدبار در موبایل به‌صورت کشویی با پس‌زمینه‌ی تیره (backdrop) باز می‌شود، جدول‌ها با اسکرول افقی نمایش داده می‌شوند، دکمه‌ها و آیتم‌های ناوبری حداقل ۴۴ پیکسل ارتفاع دارند (استاندارد لمسی)، و اینپوت‌ها روی موبایل فونت ۱۶px دارند تا از زوم خودکار سافاری/کروم جلوگیری شود.

## دوزبانگی (فارسی / انگلیسی)

دکمه‌ی «EN / FA» بالای هر صفحه، بین فارسی و انگلیسی سوییچ می‌کند و جهت صفحه (راست‌چین ↔ چپ‌چین) را هم خودکار عوض می‌کند. ترجمه‌ها در دیکشنری `FA_EN` داخل `js/script.js` تعریف شده‌اند و به‌صورت خودکار روی متن‌های صفحه اعمال می‌شوند. برای افزودن رشته‌ی ترجمه‌ی جدید، کافیست یک ورودی `'متن فارسی':'English text'` به دیکشنری اضافه کنید.

## مسیر خرید و پرداخت

`cart.html` → `checkout.html` → (`payment-success.html` / `payment-failed.html` / `payment-pending.html`)

صفحه‌ی سبد خرید شامل مدیریت تعداد، حذف کالا، اعمال کد تخفیف و محاسبه‌ی زنده‌ی جمع کل است. صفحه‌ی تسویه حساب فرم اطلاعات ارسال و انتخاب درگاه پرداخت (زرین‌پال، ملت، سامان، زیبال) را نمایش می‌دهد. این مسیر هم کاملاً نمایشی و فرانت‌اند است — برای اتصال واقعی باید به درگاه پرداخت و API سفارش خودتان وصل شود.

## صفحات خطا

`errors/404.html`، `errors/403.html` و `errors/500.html` برای حالت‌های رایج خطا آماده‌اند و می‌توانید آن‌ها را به تنظیمات مسیریابی خطای سرور خود (مثل Nginx یا فریمورک بک‌اند) متصل کنید.

## مسیر احراز هویت (Auth flow)

- **ورود**: `auth/login.html` → `index.html`
- **ثبت‌نام**: `auth/register.html` → `auth/verify-email.html` (کد ۵ رقمی) → `index.html`
- **فراموشی رمز**: `auth/login.html` → `auth/forgot-password.html` → `auth/verify-reset-code.html` → `auth/reset-password.html` → `auth/login.html`
- **خروج**: دکمه «خروج از حساب» پایین سایدبار در تمام صفحات پنل → `auth/login.html`

این مسیر کاملاً فرانت‌اند و نمایشی است (کدهای OTP بررسی واقعی نمی‌شوند). برای اتصال واقعی، درخواست‌های fetch/AJAX به API احراز هویت خودتان را در بخش‌های مربوطه‌ی `js/script.js` و اسکریپت‌های داخل هر صفحه جایگزین کنید.

هیچ فریمورکی لازم نیست. کافیه پوشه رو باز و `index.html` (یا `auth/login.html` برای شروع از صفحه ورود) رو در مرورگر اجرا کنید.

## سفارشی‌سازی رنگ‌ها

تمام رنگ‌ها به‌صورت CSS Variable در ابتدای `css/style.css` تعریف شده‌اند:

```css
:root{
  --gold:#E8A33D;      /* رنگ اصلی برند */
  --navy-900:#0B1220;  /* پس‌زمینه تیره */
  ...
}
[data-theme="light"]{ ... } /* رنگ‌های حالت روشن */
```

برای تغییر پالت رنگی، فقط همین متغیرها را ویرایش کنید — بقیه‌ی فایل به‌صورت خودکار به‌روزرسانی می‌شود.

## اتصال به بک‌اند

این قالب فقط Front-end است و داده‌ها به‌صورت نمونه (mock) در `js/script.js` (آرایه `ORDERS`) و مستقیم در HTML قرار دارند. برای اتصال واقعی:

- فرم ورود (`auth/login.html`) در حال حاضر با `submitLogin()` مستقیم به `index.html` هدایت می‌شود — این تابع را با فراخوانی API خودتان جایگزین کنید.
- جدول سفارش‌ها (`orders.html`) را می‌توانید با فراخوانی fetch/AJAX جایگزین آرایه‌ی `ORDERS` کنید.
- فرم افزودن محصول (`add-product.html`) نیاز به اتصال `action`/`fetch` به سرور شما دارد.
